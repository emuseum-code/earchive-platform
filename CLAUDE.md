# Архів: розпізнавання архівних документів: контекст для Claude Code

Мова спілкування із замовником: українська. Замовник: Дмитро (emuseum). Почалося 30.10.2026 з ТЗ «Система обліку та розпізнавання архівних облікових справ», технічних вимог, інструкції адміністратора і зразка xlsx (аркуші «Скани», «Адаптація для РМФУ», «Звіт про адаптацію для РМФУ»).

Пов'язаний проєкт: адмінка РМФУ (emuseum-code/mincult-2). Звідти взято composer.json і стиль коду.

## Правила

- Кожну готову зміну одразу пушити в `main`.
- Docker-образи не збирати на спільному VPS, тільки на GitHub Actions.
- Ключі (GEMINI_API_KEY, паролі) тільки в `.env` або GitHub Secrets, у код не писати.

## Підводні камені Filament 5

- У замиканнях параметри мають називатися `$record`, `$query`, `$data`, `$state`. Типізований `Builder $q` отримує новий екземпляр із контейнера, і фільтр не працює.
- Після `composer install` треба `php artisan filament:assets`, інакше сторінки без стилів.
- Моделям потрібні `$attributes` з дефолтами статусів, бо після `create()` атрибутів з БД немає.
